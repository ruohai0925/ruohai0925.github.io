# Ruohai's Blog

Personal blog exploring the intersection of **Computational Fluid Dynamics (CFD)** and **Artificial Intelligence**.

**Live site**: [ruohai0925.github.io](https://ruohai0925.github.io)

## Blog Posts

- [The Second Half of Computational Fluid Dynamics](https://ruohai0925.github.io/The-Second-Half/) — How AI is reshaping CFD education, development, and industrial applications.
- [The Last Solver You'll Never Build: An AI-First CFD Architecture](https://ruohai0925.github.io/CFD-AI-Technical-Vision/) — A technical vision for replacing monolithic CFD solvers with AI-assembled, case-specific solvers from pre-verified atomic building blocks.

## Tech Stack

- [Jekyll](https://jekyllrb.com/) + [Minima](https://github.com/jekyll/minima) theme
- Hosted on [GitHub Pages](https://pages.github.com/)
- Comments powered by [Giscus](https://giscus.app/) (GitHub Discussions)

## Local Development

```bash
gem install bundler jekyll
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`.
